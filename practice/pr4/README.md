# ПР4. Client-Side Prediction и Server Reconciliation

**Ветка:** `feature/prediction`. Документы: `docs/Prediction_Implementation.md`, `docs/Prediction_Test_Matrix.md`, `docs/media/`.
Unreal Engine в Nomi не нужен: те же идеи реализованы для перемещения маркера пользователя на карте.

## Соответствие терминов
| Unreal | Nomi |
|---|---|
| Server authority | сервер проверяет скорость перемещения (`validateMove`, ≤ 70 м/с) |
| Autonomous Proxy | ваш маркер «Я» |
| Simulated Proxy + smoothing | маркеры друзей с плавным подтягиванием (`smooth()`) |
| Saved Move | массив `pend` (seq, позиция, время) |
| ServerMove | `POSITION` (клиент отправляет **намерение**, а сервер проверяет) |
| ClientAdjustPosition | пакет `CORRECTION` (отклонённый seq и авторитетная позиция) |
| Replay | `reconcile()`: проигрывание неподтверждённых ходов от позиции сервера |
| Действие, чувствительное к задержке | перемещение по тапу (+ кнопка ⚡ для намеренного расхождения) |

## Сценарии
- **Без предсказания:** `/?csp=0&lag=100`: маркер двигается только после ACK (≈ 200 мс), в уведомлении видна задержка «ввод → реакция».
- **С предсказанием:** `/?lag=100`: маркер двигается сразу.
- **Коррекция:** кнопка ⚡ (прыжок на ~550 км): сервер отклоняет, присылает `CORRECTION`, маркер возвращается; в логе сервера `REJECT_MOVE`.
- **Потери:** `/?lag=100&loss=0.05`.

## Матрица тестов
T1 без эмуляции, T2 100 мс без CSP, T3 100 мс с CSP, T4 150–200 мс и 3–5% потерь, T5 ⚡ при потерях. Заполните `Prediction_Test_Matrix.md` скриншотами/видео.

## Защита
- **Почему не слать координаты без проверки?** Это позволяет телепортацию и подделку геопозиции.
- **Что такое replay?** После коррекции ходы, которые сервер ещё не обработал, применяются заново поверх авторитетной позиции.
