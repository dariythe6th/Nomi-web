# Nomi

Мобильное веб-приложение: друзья на живой карте, чат, маршруты, место встречи «удобно всем», видео-кружки и реакции.
Сквозной проект для практических работ 1–6; игровая тематика заменена на социальную геолокацию.

## Запуск
```bash
npm install
npm start            # http://localhost:3000, откройте с телефона по IP в Wi-Fi или с двух вкладок
npm test
```
Камера (кружки) и GPS в браузере работают только на `localhost` или по HTTPS.
Демо-друзья (боты) появляются сами; ваша позиция появляется после тапа по карте или кнопки 📍.

## Интерфейс
Четыре вкладки: 
**Карта** (друзья, место встречи, маршрут), 
**Друзья** (поиск, статус, расстояние), 
**Чаты** (личные диалоги, счётчик непрочитанных), 
**Профиль** (имя, статус, цвет, диагностика соединения).
Тап по другу (в списке или на карте) открывает его страницу: статус, расстояние, кнопки «Написать», «Маршрут», «Встреча» (точка только для вас двоих).
Диалоги строго 1:1: сервер доставляет сообщение только адресату (`to`). Демо-друзья отвечают автоматически.

## Структура
| Путь | Назначение |
|---|---|
| `shared/protocol.mjs` | заголовок пакета, сериализация, валидация (ПР1) |
| `shared/reliability.mjs` | ReliableChannel, AdaptiveTimeout (ПР3) |
| `shared/geo.mjs` | расстояния, проверка скорости, точка встречи |
| `shared/crypto.mjs` | ECDH + AES-256-GCM (ПР6) |
| `server/server.js` | авторитетный сервер, репликация, статистика `/stats` |
| `public/` | интерфейс (карта Leaflet, чат, кружки) |
